# 财富自由计算器

一个零依赖的静态页面，发布在 https://zgzlcc.github.io/wealth/ ，与相册站、`/time/` 相互独立。所有计算都在浏览器里完成，不联网、不写服务端。

## 能做什么

- **算需要多少**：填入人均月消费、单人还是夫妻、年收益率与通货膨胀率，再加上育儿、健康与重大投入，得到需要的资产总额和四项各自占比；同时按初始资产、月均工资、工资年增长率与工作时长逐月推演，给出这笔钱能撑多少年。工作结束时攒下的钱不够付专项支出时，会直接提示差多少。
- **按目标反推**：填「希望第几年花完」，勾出要反推的项（日常生活、育儿、健康、重大投入、月均工资、工作时长）。页面先推演到工作结束，把那时攒下的钱减去没勾的项，剩下的就是可自由分配；勾中的每一项再单独反推——只改这一项、其余保持当前输入，算出它要多少才刚好撑到目标年份。
- 参数存在本机浏览器的 localStorage（`wealth-calc-v1`）；主题分「跟随系统 / 浅色 / 深色」三选一，默认跟随系统，选择记在 `wealth-theme`，换设备不会带走。

页面里的「财富自由」，指以理想的生活开支水平、不工作的方式一直维持到老，资产不缩水、购买力不下降所需要的资产。

## 计算口径

- 金额统一按万元，比率按百分比数值（`4.5` 表示 4.5%）。
- 默认值：夫妻、人均月消费 0.5 万、年收益率 4.5%、通货膨胀率 2%、孩子 1 个、每孩总成本 100 万、健康开销 150 万、重大投入（主要是房子）300 万、初始资产 0 万、月均工资 1.2 万、工资年增长率 5%、工作时长 30 年；按默认值算出的结果是 1,030 万，这笔钱够撑 40.9 年。反推默认希望第 40 年花完，默认勾选重大投入。
- 生活本金 = 家庭月消费 × 12 ÷（年收益率 − 通货膨胀率）；夫妻按两人计，所以填的是人均月消费。
- 育儿 = 孩子数量（向下取整到整数）× 每孩总成本。
- 反推时，可自由分配 = 工作结束那年攒下的钱 − 未被反推项的金额之和；固定项已经超过这笔钱时给出负数并提示缺口。
- 「初始资产」是推演起点，只影响能撑多少年与反推时可分配的总额。
- 撑多少年按逐月推演：每月先记理财收益，工作年限内加上当月工资（按年增长率逐年上调），再扣当月生活费（按通胀逐年上调）；育儿、健康与重大投入合计那笔钱，在工作年限结束的那个月一次扣掉；资产降到 0 的那个月就是花完的时点，超过 100 年按「花不完」显示。反推时每一项各自求解，其余参数保持当前输入：工资用二分找出刚好撑到目标年份的最小值，工作时长逐年找出最小的可行年数。

## 本地运行

```bash
cd wealth
npm run dev     # http://127.0.0.1:5182/
npm test        # 计算与格式化的边界检查
```

想验证真正发布出去的形态（`/wealth/` 子目录）：

```bash
pnpm build      # 在仓库根目录执行
pnpm preview    # http://localhost:4321/wealth/
```

`astro dev` 不会提供 `/wealth/`：开发服务器只读源码，这个路径会被相册站的通配路由接走。

## 发布位置

仓库根目录的 `pnpm build` 依次执行 Astro 构建、pagefind 索引与 `script/momo/build-web.js`；后者在复制 `/time/` 之后，把本目录的 `index.html`、`icon.svg` 与 `src/` 复制到 `dist/wealth/`，随 GitHub Pages 一起上线。`test/`、`scripts/`、`package.json` 与本文档不参与部署。
